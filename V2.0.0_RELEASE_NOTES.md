# CampusFix V2.0.0 — Final Integration & Release (Historical)

## Release integration
- Consolidates the V1.11.0–V1.18.0 feature work into the V2.0.0 package.
- Adds a GitHub Actions CI workflow to install the lockfile dependencies, run the secret-name scan and production build, and validate internal routes on pushes and pull requests to `main`/`master`.
- Adds a release-structure check for required application, Firebase rules, AI endpoint, and configuration files.
- Keeps the existing role-aware application features, AI advisory endpoint, predictive insights, campus intelligence, and UI updates in the integrated source tree.

## Local release validation
Run from the project root:

```bash
npm ci
npm run check:release
npm run check:links
npm run build
```

## Firebase release validation
Review the rules against the actual Firebase data model, then deploy deliberately:

```bash
firebase deploy --only firestore:rules,storage
```

Test with separate student, assigned-worker, unassigned-worker, and administrator accounts. Verify complaint creation, image uploads, assignment, status transitions, reopen requests, notifications, reviews, and AI endpoint authorization.

## Environment configuration
- Keep browser Firebase settings in the existing `VITE_FIREBASE_*` variables.
- Keep the AI provider key server-side only; never expose it through browser-prefixed environment variables.
- Configure the Vercel server-side AI environment variables documented in `.env.example` and the Phase 4 changelog.

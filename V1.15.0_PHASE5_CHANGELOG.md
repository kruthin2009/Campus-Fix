# CampusFix V1.15.0 — Phase 5: Predictive Maintenance Intelligence

## Implemented
- Added 30-day versus previous-30-day complaint volume comparison.
- Added 90-day recurring issue detection grouped by tower, department and room.
- Added elevated/watch risk signals based on repeat count and still-active complaints.
- Added practical inspection recommendations for recurring patterns.
- Added per-tower complaint trend comparison.
- Added data sufficiency indicator so sparse history is clearly marked limited.
- Signals are explicitly described as historical trend analysis, not guaranteed equipment-failure forecasts.
- No automated work orders, priority changes, or assignments are made.

## Data and limitations
- Uses existing `reports` documents and their `createdAt`, tower, department, room and status fields.
- Records without a valid `createdAt` timestamp are excluded from time-window calculations.
- No external sensor/IoT data, predictive ML model, or scheduled maintenance write-back is included.
- All calculations run client-side over the live reports already loaded in the admin Smart Center.

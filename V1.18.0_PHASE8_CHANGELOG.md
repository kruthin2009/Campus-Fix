# CampusFix V1.18.0 — Phase 8: UI & Branding

## Implemented
- Refreshed design tokens for a consistent cool campus-blue palette with warm amber accent.
- Redesigned portal sidebar branding, navigation active states, sign-out control and top bar.
- Improved portal spacing, typography hierarchy, surfaces, tables, form controls and focus states.
- Refined public landing-page hero, metric cards, workflow cards and portal choices.
- Improved mobile portal sizing, user identity display and horizontal table overflow.
- Added reduced-motion support for users who request less animation.
- Updated portal and login release labels to V1.18.0.
- Preserved existing functionality, routes, Firebase integration and light/dark theme support.

# CampusFix V1.13.0 — Administrator Command Centre

## Implemented in this phase
- Live complaint analytics on the existing admin dashboard.
- Complaint totals by tower, including active and urgent counts.
- Department workload breakdown, including active complaint counts.
- A 72-hour ageing indicator for active complaints. This is an operational flag, not a configured SLA policy.
- Urgent active complaint queue with links to complaint details.
- CSV export of the complaints currently returned by the admin reports subscription.

## Data and permissions
- Analytics use the existing `subscribeToAllReports` Firestore service; no new collections or security rules are introduced.
- The export is generated in the browser and includes complaint ID, title, tower, room, department, priority, status, assignment and creation time.
- Dashboard analytics require the administrator's existing report-read permissions. The export is available only to signed-in admins viewing this page.

## Not included
- PDF export, configurable SLA targets, audit-log analytics, worker performance scoring, or automated performance rankings.
- The 72-hour threshold is a fixed warning threshold, not a contractual SLA.

## Validation required
1. Run `npm ci` and `npm run build`.
2. Sign in as an administrator and verify tower/department totals against the complaints list.
3. Verify urgent queue links open the correct complaint.
4. Export CSV and confirm it opens with the expected columns.
5. Confirm the page shows a useful error if the complaint subscription is denied or unavailable.
6. Deploy after testing.

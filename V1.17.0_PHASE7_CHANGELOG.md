# CampusFix V1.17.0 — Phase 7: Security & Reliability

## Changes
- Replaced Storage rules that denied all report media uploads with scoped rules matching the actual app upload paths.
- Student report images may only be created under the authenticated student's own UID folder.
- Worker completion images may only be created for a report assigned directly to that worker or to their team, and only with a `completion-` filename.
- All image uploads are limited to 5 MB and JPEG/PNG/WebP. Existing report media cannot be overwritten or deleted through these report paths.
- Tower image uploads remain administrator-only.
- Firestore report creation now uses a strict field allowlist, validates key text lengths and priority values, and prevents students from setting initial worker/team assignments.
- Existing role-based reads, updates, reopen-request controls and audit-log immutability remain in place.

## Deployment
1. Review `firestore.rules` and `storage.rules` against the live Firebase project.
2. Deploy with `firebase deploy --only firestore:rules,storage`.
3. Test as student, assigned worker, unassigned worker, and each administrator role.
4. Confirm complaint photo upload and worker completion photo upload.

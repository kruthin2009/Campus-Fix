# CampusFix V2.0.8 — Blue UI refinement

## Design direction
- Blue university palette with restrained accent colours.
- Consistent typography, border, surface, spacing and shadow tokens.
- Refined persistent left sidebar, active navigation states and top bar.
- Balanced content width and card density across student, worker and administrator portals.
- Improved form focus states, button hierarchy and complaint card interactions.
- Mobile spacing and compact-screen adjustments.
- Coordinated dark theme tokens for the same blue palette.

## Preserved
Existing routes, role guards, Firebase integration, complaint workflows, worker operations, announcements, maintenance, reopen requests and administration pages were not intentionally removed or rewritten in this styling pass.

## AI removal check
A source scan of `src`, `public` and `api` found no AI provider references, AI API routes, AI News, or Smart Center references at the time of packaging.

## Verification
- `node scripts/release-check.mjs`: passed.
- `node scripts/check-links.mjs`: passed.
